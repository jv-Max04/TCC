# Rotas da API declaradas contra testes de contrato

> **O cliente deste contrato é a janela Windows.** A API é a **camada interna do executável**: a
> janela a sobe no próprio processo, numa *thread*, em `127.0.0.1` com porta efêmera
> (`src/refino/desktop/servidor.py`), e fala com ela por HTTP.

**Este arquivo é o insumo da OITAVA superfície de exaustividade.** As sete anteriores estão
tabeladas na §8.5; esta responde à mesma pergunta que elas — *o que foi declarado num lugar aconteceu
no outro?* — com rota de API no lugar de seção, artefato ou item de teste.

**Por que ele existe.** O `[CA-12.4]` pede *"um teste de contrato por rota"*. Sem enumerar as rotas, isso
é cosmético: quem escreve o teste também escolhe o que conta como "rota", e a contagem fica verdadeira
por construção. É a mesma lacuna que a sétima superfície fechou para os `[TO-N.M]`, e a primeira
execução daquele portão achou **46 de 54** nós que não resolviam.

## Como ler

O portão é `tests/test_api_contrato.py` e confere **quatro** coisas:

1. **Bijeção, direção A.** Toda rota da aplicação tem exactamente uma linha aqui. Rota nova sem linha
   reprova — é a cláusula que pega funcionalidade acrescentada sem contrato.
2. **Bijeção, direção B.** Toda linha aqui corresponde a uma rota existente. Entrada órfã reprova — é a
   cláusula que pega **renomeação**, e é a que o desenho óbvio esquece.
3. **O nó existe.** `arquivo::função` é resolvido por análise sintática do arquivo de teste. Nome
   inventado reprova.
4. **A OpenAPI lista as mesmas rotas.** Igualdade de conjuntos, não subconjunto: subconjunto passaria
   com rota oculta da documentação.

**O que ele NÃO pega, e a lacuna vai nomeada:** linha apontando para teste vivo que exercita outra
rota. É proxy pela forma, com a força e o limite que isso tem.

## Escopo: o que conta como rota

Só `fastapi.routing.APIRoute`. As rotas que o FastAPI acrescenta por conta — `/openapi.json`, `/docs`,
`/docs/oauth2-redirect`, `/redoc` — são `starlette.routing.Route` e ficam fora: não são contrato nosso,
e exigir teste para elas seria testar o framework.

**A discriminação é por TIPO e não por lista de caminhos**, de propósito. Uma lista de caminhos a
ignorar caduca quando o FastAPI acrescenta rota interna, e o modo de falha seria uma rota do framework
exigindo contrato nosso — portão que sempre reprova.
